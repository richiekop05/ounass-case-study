# Database reference

Generated by `uv run python scripts/db_reference.py` from `db/migrations/*.sql`. Do not edit by hand.

All tables are in the `public` schema of a Supabase (Postgres) project. Row level security is on with no policies, so only the service key (used by the command line and the two local apps) can read or write. Migrations are applied in file order and recorded in `schema_migrations`; `scraper migrate`, `catalog migrate` and `richies setup` all apply the ones not yet applied. Migration `001_scraper.sql` also creates the private storage bucket `product-images` for product photos.
